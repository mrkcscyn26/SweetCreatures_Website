# Sweet Creatures Website

A website for **Sweet Creatures**, a pastry and coffee shop offering handcrafted cakes, cupcakes, pastries, pasta, snacks, and specialty beverages. This repository contains the Phase 1 web development scaffold.

## Project Description

This project serves as the foundational frontend skeleton for the Sweet Creatures web application. In Phase 1, the repository is set up with semantic HTML5 structures and organized CSS section headings, ready for collaborative development and future styling.

## How to Run Locally with Live Server

1. Open this repository folder (`SweetCreatures_Website`) in **Visual Studio Code**.
2. Make sure the **Live Server** extension (by Ritwick Dey) is installed from the VS Code Extensions Marketplace (`Ctrl+Shift+X`).
3. Right-click on `index.html` in the file explorer and choose **"Open with Live Server"** (or click **"Go Live"** in the status bar at the bottom right).
4. Live Server will launch the project in your default web browser (typically at `http://127.0.0.1:5500/index.html`).
